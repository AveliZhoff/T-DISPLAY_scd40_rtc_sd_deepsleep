# Proposal

## Why

Нужен простой способ выбирать, будет ли дисплей работать при запуске устройства, не меняя поведение текущего цикла сразу после выбора. Это позволит отключить дисплей для экономии энергии или оставить его включенным и увидеть выбранное состояние при переключении.

## What Changes

- При пробуждении нажатием любой кнопки проверять, удерживается ли вторая кнопка GPIO35 не менее одной секунды.
- При удержании переключать и сохранять режим дисплея `on`/`off`; показывать соответствующее сообщение `display on` или `display off` в течение одной секунды.
- Не применять выбранный режим сразу: новое состояние дисплея использовать начиная со следующего запуска устройства.
- Не проверять кнопку GPIO35 и не переключать режим при пробуждении по таймеру.
- Сохранить выбранный режим между перезапусками, включая отключение питания.

### Modified Capabilities

- `device-lifecycle`: определить переключение режима дисплея при запуске по удержанию кнопки и применение сохраненного режима со следующего запуска.

## Impact

- Прошивка: `src/main.cpp`, `src/display.cpp`, `src/display.h`; для постоянного хранения настройки может потребоваться использовать ESP32 Preferences/NVS.
- Документация: `README.md`.
- Поведение дисплея при таймерном пробуждении: сохраненный режим имеет приоритет над текущим автоматическим отключением подсветки без USB.
