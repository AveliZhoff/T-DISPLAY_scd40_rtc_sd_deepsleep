# Proposal

## Why

Настройки сети и параметры ThingSpeak для одного устройства сейчас разнесены по двум заголовкам и двум примерам. Их объединение в `device_config.h` упростит выбор конфигурации устройства и позволит хранить все локальные учетные данные в одном игнорируемом Git файле.

## What Changes

- Перенести конфигурации точек доступа Wi-Fi для каждого устройства в `src/device_config.h`.
- Объединить Wi-Fi и ThingSpeak примеры в `src/device_config.example.h`.
- Удалить отдельные `src/wifi_config.h` и `src/wifi_config.example.h`, обновить подключения прошивки и инструкции README.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `device-configuration`: единый локальный заголовок и единый пример содержат параметры устройства и Wi-Fi.

## Impact

Изменения затрагивают конфигурационные заголовки в `src/`, их потребителей в прошивке и README. Внешние API и зависимости не меняются.
