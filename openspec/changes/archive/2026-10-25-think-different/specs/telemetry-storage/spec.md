# Spec Delta

## MODIFIED Requirements

### Requirement: Буферизация на SD-карте

Если SD-карта доступна, устройство MUST хранить неотправленные записи в `/measurements.csv` в CSV-формате с девятью полями. Перед отправкой устройство MUST загружать не более 11 накопленных записей. Ошибка инициализации SD-карты MUST NOT останавливать измерение и попытку сетевой отправки. При недоступности Wi-Fi устройство MUST добавлять измерение в очередь не чаще одного раза за `thingSpeakSendIntervalSeconds`, проверяя интервал относительно последней сохраненной записи; промежуточные измерения MUST пропускаться. Timestamp сохраненной записи MUST оставаться временем фактического измерения.

#### Scenario: Ошибка отправки

- GIVEN SD-карта доступна и отправка ThingSpeak завершилась ошибкой
- WHEN устройство обрабатывает результат отправки
- THEN текущая запись добавляется в конец очереди, а ранее накопленные записи сохраняются

#### Scenario: SD-карта недоступна

- GIVEN SD-карту не удалось инициализировать
- WHEN устройство получает новое измерение
- THEN оно продолжает обработку и сетевую отправку без локальной очереди

#### Scenario: Офлайн-измерение сохранено по интервалу ThingSpeak

- GIVEN Wi-Fi недоступен, SD-карта доступна и с момента последней записи в очереди прошло не менее `thingSpeakSendIntervalSeconds`
- WHEN устройство получает новое измерение
- THEN оно сохраняет это измерение с фактическим timestamp в конец очереди

#### Scenario: Офлайн-измерение пропущено до истечения интервала

- GIVEN Wi-Fi недоступен, SD-карта доступна и с момента последней записи в очереди прошло менее `thingSpeakSendIntervalSeconds`
- WHEN устройство получает новое измерение
- THEN оно не добавляет измерение в очередь и оставляет существующие записи без изменений

#### Scenario: Отправка накопленных офлайн-измерений

- GIVEN Wi-Fi восстановлен и в очереди есть офлайн-измерения
- WHEN наступает разрешенная попытка ThingSpeak
- THEN устройство отправляет сохраненные записи обычным пакетным способом без изменения их timestamp
