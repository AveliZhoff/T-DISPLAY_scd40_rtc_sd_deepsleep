# Tasks

## 1. Индикация инициализации ThingSpeak

- [x] 1.1 Выполнять подключение Wi-Fi до инициализации ThingSpeak; при неудаче Wi-Fi не вызывать `thingSpeakBegin()` и оставлять индикатор ThingSpeak серым, сохраняя обработку измерения для повтора. После успешного подключения отображать желтый при инициализации, зеленый при успешной отправке и красный при ошибке. Проверить ветви пропуска по интервалу, ошибки Wi-Fi, ошибки инициализации и ошибки отправки.
- [x] 1.2 Собрать прошивку командой `pio run -e lilygo-t-display` и убедиться, что сборка завершается успешно.
- [x] 1.3 Проверить на устройстве: при неистекшем интервале индикатор ThingSpeak серый; при разрешенной попытке он желтый, затем зеленый при успехе или красный при ошибке.
