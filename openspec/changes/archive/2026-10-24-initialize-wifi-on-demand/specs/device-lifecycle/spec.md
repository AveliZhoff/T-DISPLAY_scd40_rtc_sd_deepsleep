# Spec Delta

## MODIFIED Requirements

### Requirement: Подключение к Wi-Fi с офлайн-режимом

Устройство MUST подключаться к настроенным точкам доступа только при необходимости синхронизировать RTC или выполнить разрешенную попытку отправки текущего либо сохраненных измерений в ThingSpeak. Если сетевая операция не требуется, устройство MUST пропускать инициализацию Wi-Fi. При неудачном подключении устройство MUST продолжить автономную работу с доступными датчиками, RTC и SD-картой, сохраняя неотправленные измерения.

#### Scenario: Точка доступа доступна

- GIVEN требуется синхронизация RTC или наступила разрешенная попытка отправки измерений, а настроенная точка доступа доступна
- WHEN устройство подключается к Wi-Fi
- THEN оно подключается в режиме станции и продолжает требуемую сетевую операцию

#### Scenario: RTC требует синхронизации

- GIVEN обычный запуск обнаружил потерю питания RTC
- WHEN устройство пытается синхронизировать время через NTP
- THEN оно подключается к Wi-Fi для синхронизации; если подключение недоступно, устройство продолжает работу с имеющимся временем RTC без Wi-Fi

#### Scenario: Наступила разрешенная отправка измерений

- GIVEN получено текущее измерение и/или на SD-карте есть неотправленные измерения, а интервал отправки позволяет выполнить попытку
- WHEN устройство готовит данные к отправке в ThingSpeak
- THEN оно подключается к Wi-Fi и пытается отправить текущие и сохраненные измерения

#### Scenario: Синхронизация и отправка не требуются

- GIVEN RTC не требует синхронизации и наступившей попытки отправки измерений нет
- WHEN устройство выполняет цикл без сетевой операции
- THEN оно не инициализирует Wi-Fi и продолжает обработку цикла

#### Scenario: Ни одна точка доступа недоступна

- GIVEN требуется синхронизация RTC или отправка измерений, но все настроенные попытки подключения завершились неудачно
- WHEN устройство продолжает цикл
- THEN оно работает офлайн, а неотправленные измерения остаются сохраненными для последующей попытки
