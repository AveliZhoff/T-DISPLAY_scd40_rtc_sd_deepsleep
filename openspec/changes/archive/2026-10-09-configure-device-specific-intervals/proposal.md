# Proposal

## Why

Интервалы сна и отправки данных ThingSpeak сейчас заданы общими значениями в `main.cpp`, поэтому устройства с разными `DEVICE_NUM` не могут иметь собственное расписание. Перенос интервалов в конфигурацию устройства позволит независимо настраивать каждый контроллер, сохранив текущее поведение по умолчанию.

## What Changes

- Перенести `DEEP_SLEEP_INTERVAL_SECONDS` и `THINGSPEAK_SEND_INTERVAL_SECONDS` из `main.cpp` в локальную конфигурацию устройства.
- Задать отдельные значения этих интервалов для каждого поддерживаемого `DEVICE_NUM` (1–3).
- Сохранить текущие значения по умолчанию: 30 секунд до пробуждения по таймеру и 300 секунд между отправками ThingSpeak для всех трех устройств; дальнейшие изменения каждого устройства не должны затрагивать остальные.
- Обновить шаблон `src/device_config.example.h` и документацию без добавления локальных секретов в Git.
