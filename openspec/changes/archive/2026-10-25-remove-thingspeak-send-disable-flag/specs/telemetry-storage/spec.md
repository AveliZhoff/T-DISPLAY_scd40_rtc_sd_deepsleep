# Spec Delta

## REMOVED Requirements

### Requirement: Режим без сетевой отправки

**Reason**: Compile-time флаг и связанная с ним ветка обработки удаляются; прошивка больше не поддерживает режим, в котором отправка ThingSpeak отключена.

**Migration**: Использовать штатный цикл отправки текущих и накопленных измерений ThingSpeak с учетом интервала. При ошибке отправки текущая запись сохраняется в очереди SD-карты, если карта доступна.
