# Proposal

## Why

Флаг `DISABLE_THINGSPEAK_SEND` сейчас безусловно отключает сетевую отправку измерений, хотя в прошивке уже реализован и описан цикл пакетной отправки ThingSpeak. Удаление этого режима позволит выполнять штатную отправку при каждом разрешенном интервалом цикле и сохранять записи на SD-карте только для повторной отправки при ошибках.

## What Changes

- Удалить compile-time флаг и связанный с ним ранний выход, который сохраняет только текущую запись и усыпляет устройство.
- Оставить штатную пакетную отправку ThingSpeak, очередь неотправленных данных на SD-карте, поведение при ошибке и ограничение интервала.
- Удалить из спецификации требование о режиме отключенной сетевой отправки.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `telemetry-storage`: удалить контракт режима `DISABLE_THINGSPEAK_SEND`; обычный цикл обработки измерения использует существующий интервал попытки отправки и пакетную отправку с предусмотренным сохранением при ошибке.

## Impact

- `src/main.cpp`: compile-time флаг, условная ветка обхода отправки и относящиеся к ней сообщения журнала.
- `openspec/specs/telemetry-storage/spec.md`: поведение отправки и буферизации.
- ThingSpeak API, формат пакетного запроса, настройки устройства, зависимости PlatformIO и протокол SD-очереди не меняются.
