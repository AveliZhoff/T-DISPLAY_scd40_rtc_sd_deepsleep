# Design

## Context

Прошивка включает `device_config.h` напрямую, поэтому сохраняется существующий путь `src/device_config.h` для локального файла. Проект поддерживает несколько значений `DEVICE_NUM`, каждое со своим hostname, каналом и Write API Key. См. proposal.md — Why.

## Goals / Non-Goals

**Goals:**

- Не включать локальную конфигурацию устройства в обычный набор файлов Git.
- Сохранить совместимость с текущими include прошивки.
- Дать разработчику шаблон с понятными демонстрационными каналами и явными плейсхолдерами API-ключей.

**Non-Goals:**

- Менять runtime-поведение Wi-Fi или ThingSpeak.
- Автоматически создавать локальный файл во время сборки.
- Отзывать учетные данные или переписывать историю репозитория.

## Decisions

- Использовать точечное правило `.gitignore` для `src/device_config.h`, сохраняя соседние файлы конфигурации и пример отслеживаемыми. Альтернатива — игнорировать весь каталог `src` или все заголовки конфигурации — скрыла бы необходимые исходные файлы.
- Держать `src/device_config.example.h` рядом с ожидаемым заголовком и описать копирование в README. Такое копирование сохраняет текущий include-контракт; генерация конфигурации флагами сборки потребовала бы менять способ передачи конфигурации в прошивку.
- Удалить уже отслеживаемую локальную конфигурацию из индекса, не удаляя локальную копию. `.gitignore` не исключает файлы, которые уже находятся под отслеживанием.
- Использовать неперсональные номера каналов-примеров и явные плейсхолдеры вместо рабочих ключей. Шаблон показывает структуру для каждого поддерживаемого номера устройства, но не содержит действительных учетных данных.

## Risks / Trade-offs

- [Секрет мог попасть в предыдущие коммиты] → игнорирование и удаление из текущего дерева не очищают историю; при необходимости ключи следует заменить, а историю обрабатывать отдельно.
- [Разработчик может забыть создать локальный заголовок] → README содержит команду копирования шаблона до сборки.
- [Плейсхолдер API-ключа не подходит для отправки данных] → перед прошивкой разработчик должен заменить его действительным ключом и указать собственные номера каналов.

## Migration Plan

1. Удалить `src/device_config.h` из Git-индекса, оставив существующий локальный файл.
2. Добавить ignore-правило, шаблон конфигурации и инструкцию копирования.
3. На новой рабочей копии скопировать пример в `src/device_config.h`, заполнить значения устройства и собрать прошивку.

Откат: вернуть отслеживание `src/device_config.h` только после проверки, что в него не попадут реальные секреты; иначе оставить локальную конфигурацию вне индекса.
