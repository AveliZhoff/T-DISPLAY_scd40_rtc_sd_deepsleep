# Proposal

## Why

Локальная конфигурация устройства содержит учетные данные ThingSpeak и не должна попадать в Git. После клонирования проекта разработчику нужен безопасный пример, по которому можно создать локальный конфигурационный заголовок для сборки прошивки.

## What Changes

- Исключить `src/device_config.h` из Git и хранить в репозитории только шаблон без реальных секретов.
- Добавить пример с настройкой номера устройства, hostname, номера канала и явными плейсхолдерами API-ключей.
- Документировать создание локального файла из примера.

## Capabilities

### New Capabilities

- `device-configuration`: безопасное хранение локальной конфигурации устройства и наличие шаблона для ее создания.

### Modified Capabilities

Нет.

## Impact

Изменения затрагивают `.gitignore`, `src/device_config.example.h` и инструкции в `README.md`. Локальный `src/device_config.h` остается входным файлом конфигурации, используемым прошивкой; интерфейсы прошивки и зависимости не меняются.
