# Конфигурация устройства

## Purpose

Определяет безопасное хранение конфигурации конкретного устройства и наличие проверяемого шаблона, из которого разработчик создает локальный заголовок перед сборкой прошивки.

## Requirements

### Requirement: Локальная конфигурация устройства не включается в Git

Репозиторий MUST игнорировать локальный файл `src/device_config.h`, содержащий настройки ThingSpeak и точки доступа Wi-Fi конкретного устройства, не удаляя его из локальной рабочей копии.

#### Scenario: Локальный файл конфигурации присутствует

- **GIVEN** разработчик настроил `src/device_config.h` с параметрами ThingSpeak и Wi-Fi
- **WHEN** Git проверяет этот файл как неотслеживаемое изменение
- **THEN** файл игнорируется, но остается доступным локальной сборке прошивки

### Requirement: Шаблон конфигурации не содержит реальные секреты

Репозиторий MUST предоставлять единый `src/device_config.example.h` с параметрами ThingSpeak и примерами точек доступа для поддерживаемых устройств, используя плейсхолдеры вместо учетных данных.

#### Scenario: Подготовка локальной конфигурации из шаблона

- **GIVEN** разработчик клонировал репозиторий без локального `src/device_config.h`
- **WHEN** он копирует пример в `src/device_config.h` и задает собственные параметры
- **THEN** локальный заголовок предоставляет прошивке настройки устройства и Wi-Fi, а шаблон не раскрывает реальные учетные данные

### Requirement: Интервалы задаются отдельно для каждого устройства
Для каждого поддерживаемого номера устройства конфигурация MUST задавать интервал deep sleep и интервал отправки ThingSpeak независимо от других устройств.

#### Scenario: Выбор интервалов по номеру устройства
- **GIVEN** задан поддерживаемый номер устройства
- **WHEN** прошивка использует интервалы сна и отправки данных
- **THEN** она использует оба значения, настроенные для этого номера устройства, не затрагивая настройки интервалов других устройств

#### Scenario: Сохранение начальных интервалов
- **GIVEN** в конфигурации устройств оставлены исходные значения
- **WHEN** прошивка выбирает интервалы для любого поддерживаемого устройства
- **THEN** интервал deep sleep составляет 30 секунд, а интервал отправки ThingSpeak — 300 секунд

#### Scenario: Независимое изменение интервала одного устройства
- **GIVEN** интервал одного устройства изменен в его конфигурации
- **WHEN** выбираются интервалы для остальных устройств
- **THEN** их интервалы остаются равными настроенным для них значениям
