# Конфигурация устройства

## Purpose

Определяет безопасное хранение конфигурации конкретного устройства и наличие проверяемого шаблона, из которого разработчик создает локальный заголовок перед сборкой прошивки.

## Requirements

### Requirement: Локальная конфигурация устройства не включается в Git

Репозиторий MUST игнорировать локальный файл `src/device_config.h`, содержащий параметры конкретного устройства, не удаляя его из локальной рабочей копии.

#### Scenario: Локальный файл конфигурации присутствует

- **GIVEN** разработчик создал `src/device_config.h` с локальными параметрами устройства
- **WHEN** Git проверяет этот файл как неотслеживаемое изменение
- **THEN** файл игнорируется, но остается доступным локальной сборке прошивки

### Requirement: Шаблон конфигурации не содержит реальные секреты

Репозиторий MUST предоставлять `src/device_config.example.h` с настройками примеров поддерживаемых устройств и плейсхолдерами вместо учетных данных.

#### Scenario: Подготовка локальной конфигурации из шаблона

- **GIVEN** разработчик клонировал репозиторий без локального `src/device_config.h`
- **WHEN** он копирует пример в `src/device_config.h` и задает собственные параметры
- **THEN** локальный заголовок предоставляет прошивке номер устройства, hostname, номер канала и Write API Key, а шаблон не раскрывает реальные учетные данные
